[ APPS // PRODUCT 01 ]

Kurukuru

A gamified, college-exclusive, peer-to-peer ride-sharing app where the city is the game board. Players clear fog from a street map, ride through a block-built 3D campus, and walk an open 3D world of real roads and shops. Behind it sits a Go core full of small, careful algorithms.

[ SYSTEM MAP ]

How it fits together

One Flutter codebase on the client, one Go monolith behind it, and a PostGIS database holding the map. Everything else is a service the core calls.

[ GO CORE // SMART CODE ]

Careful algorithms

The backend leans on small, exact pieces: geometry, queues that never double-process, sockets that cannot be stalled, and money that cannot go negative. Pick one to read the idea and the real code.

[ ALGORITHM 01 // RIDE MATCHER ]

Where do two trips overlap?

A pilot drives start to destination. A co-pilot wants a lift between two other points. The matcher projects both onto the pilot's line, checks direction, detour and overlap, and finds where to board and get off. Drag the two pink and white points to try it.

[ ENGINE 01 // VOXEL BLOCK WORLD ]

From map data to blocks

We bake any area of OpenStreetMap into a grid of 10 metre blocks. Step through the same scene: vector shapes, a 3x finer raster, the downsampled cells, and the extruded block world.

[ ENGINE 02 // STREET MAP + FOG OF WAR ]

Clear the fog

The street map is a vector MapLibre style in the Kurukuru palette. Fog is one polygon laid on top of it, with explored areas punched out as holes. Drag across the map to explore it the way a rider does.

[ ENGINE 03 // OPEN 3D WORLD ]

Real roads, real shops, in three.js

A second pipeline builds a walkable world from Overture Maps. It keeps every real bend of every road and every named shop, then streams it into a Three.js scene running inside the app.
